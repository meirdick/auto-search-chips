`meirdick/auto-search-chips` turns a plain sentence into typed filters on an Eloquent model. The user types `videos by Ada above 10k views`. The text stays in the box. Under the box, three chips show how the package read it: `Type is Video`, `Author contains Ada` and `Views greater than 10,000`. The list filters. The user can remove any chip.

This version is 0.1. It is not released. The API can change before 1.0.

## What you get

- A search box that the user can read. Each chip shows one filter.
- A rules engine that works with no AI, no API key and no network.
- An optional AI engine that adds chips for words the rules did not explain.
- An allow-list of fields, operators and value types. The AI never writes SQL.
- A PHP API: `SearchChips::for()` and the `autoSearch` scope.
- A filter panel in the Livewire and React components. It shows the same filters as controls.

## Requirements

- PHP 8.3 or later.
- Laravel 12 or 13. The package requires `illuminate/*` packages at `^12.0` or `^13.0`.

The test suite runs on PHP 8.3, 8.4 and 8.5 with Laravel 12 and 13, on SQLite. See [Limits](/limits/) for what is not tested.

## Optional packages

| Package | Use |
| --- | --- |
| `livewire/livewire` (3 or 4) | The `<livewire:search-chips>` component |
| `laravel/ai` | The chat engine (`ai`) |
| `laravel/scout` | Keyword text and chips through Scout for `Searchable` models |
| `meirdick/laravel-cf-workersai` (1.3 or later) | The transport for the System One engine. It adds retries, failover and AI Gateway routing. |

The package does not require any of these.
