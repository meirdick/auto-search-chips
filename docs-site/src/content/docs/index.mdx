<h2 class="mt-14 text-2xl font-semibold tracking-tight">One sentence in, typed filters out</h2>

<p class="mt-2 text-muted-foreground">The user types the sentence below. The package shows three chips under the box: <code>Type is Video</code>, <code>Author contains Ada</code> and <code>Views greater than 10,000</code>. You can run the same search from PHP.</p>

```php
Post::autoSearch('videos by Ada above 10k views')->paginate();
```
